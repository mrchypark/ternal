{{- if .Values.persistence.enabled }}
DATA PERSISTENCE:
  {{ .Release.Name }} stores /data on a PVC. Pod replacement preserves the
  current database, but restoring an older trust database remains unsupported
  because it could revive revoked device or grant state.
{{- else }}
DATA SAFETY WARNING:
  {{ .Release.Name }} stores /data in emptyDir and intentionally has no PVC.
  Every pod replacement, upgrade, or rollback loses the current Ternal database.
  This breaking greenfield port does not support restoring an older trust
  database because that could revive revoked device or grant state. After a
  greenfield rollout, verify the empty state and enroll devices afresh.
{{- end }}

Required secrets (create this Secret outside Helm without kubectl apply, then
reference it by name so values are not copied into Helm release history):
  helm upgrade --install {{ .Release.Name }} deploy/helm/ternal \
    --set image.tag=... \
    --set-string secrets.existingSecret=ternal-runtime
